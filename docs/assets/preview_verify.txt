# 实时预览验证记录（2026-11-05）

环境：AI 盒子 `10.10.206.68`（BM1684X，8 核，6 GiB），容器 `aidetect:dev`
（二进制与 `build/aidetect/aidetect` 同一 md5），生产盒子 `10.10.207.46` 全程只读。

## 测量方法

客户端 `.work/browser/measure_ws.mjs` 连接 `ws://<box>:9000/ws/frame?token=<JWT>`，
按协议解析 `4B header 长度 + JSON header + JPEG`：

- 尺寸：解析 JPEG SOF 得到宽高；
- 内容帧率：对每帧 JPEG 做 SHA1，按窗口内**不同 hash 数 / 秒**统计；
- 重复帧：与历史 hash 完全相同的帧，记录其时间/来源；
- 窗口：本地测试默认 10s（warm 2s），实时源默认 10~12s。

"真内容 10fps" 的判定：不同 JPEG 数/秒 ≈ 10，且重复帧为 0。

## 本地确定性源（同一台盒子的 aidetect 二进制）

| 编号 | 源 | 源帧率/分辨率 | 输出分辨率 | 包帧率 | **内容帧率** | 不同/总帧 | 重复帧 |
|---|---|---|---|---|---|---|---|
| t_big | 真实告警视频循环 | 25fps / 2560×1440 | 1920×1080 | 10.0 | **10.0** | 100/100 | 0 |
| t_hd | 真实告警视频循环 | 25fps / 1920×1080 | 1920×1080 | 10.0 | **10.0** | 100/100 | 0 |
| t_cam | 6488 摄像机 RTSP | 25fps / 2560×1440 | 1920×1080 | 9.9 | **9.9** | 99/99 | 0 |
| t_udp1 | UDP 实时回放 ref1 | 11fps / 704×480 | 704×480 | 10.0 | **10.0** | 100/100 | 0 |
| t_udp3 | UDP 实时回放 ref3 | 9fps / 704×576 | 704×576 | 9.0 | **9.0** | 90/90 | 0 |
| all_2 | 3 路活动瓦片合流 | 混合 | 1920×1080 | 9.8 | **9.8** | 98/98 | 0 |

结论：

- 2560×1440 → 1920×1080（只缩小）；
- 1920×1080 / 1280×720 / 704×576 / 704×480 原样输出（不放大）；
- 11fps 源 → 10.0fps（抽帧）；9fps 源 → 9.0fps（不补帧、不抽帧）；
- 所有场景重复帧为 0，即"真正内容"。
